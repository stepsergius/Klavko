KLAVKO — keyboard layout switcher and typing assistant for Mac
====================================================================

Klavko fixes words typed in the wrong keyboard layout by itself
(ghbdsn → привіт), fixes obvious typos, adds “quotes”, dashes and capitals,
and has voice input, translation of selected text, text from the screen and
a clipboard history. The app is free and runs entirely on your Mac: what you
type and dictate is never sent anywhere.


REQUIREMENTS
------------
• macOS 14 Sonoma or later.
• A Mac with an Apple processor (M1, M2, M3, M4…). It works on Intel Macs
  too, but voice input is slower there.
• At least two keyboard layouts, for example English (ABC or U.S.) and
  Ukrainian (Ukrainian or Ukrainian – PC). German, French, Spanish, Polish
  and others are supported too. Add them in System Settings → Keyboard →
  Input Sources → Edit.


INSTALLING
----------
1. Unzip the archive (double-click it).

2. Drag Klavko.app into the Applications folder.
   There exactly — then Klavko starts together with your Mac.

3. First launch. The app isn’t from the App Store, so macOS first warns that
   it can’t check the developer. This is expected.
   • Right-click Klavko.app → Open → Open.
   • If there is no such button (macOS 15 and later): try to open the app,
     close the warning, then open System Settings → Privacy & Security,
     scroll down and click “Open Anyway” next to the line about Klavko,
     enter your password and open Klavko again.

4. Allow keyboard access. Klavko asks for Accessibility:
   System Settings → Privacy & Security → Accessibility → turn on Klavko.
   Without this permission the app can’t see what you type.

5. Done. The flag of the current layout appears in the menu bar 🇺🇦 / 🇺🇸.
   If you see a keyboard icon with an exclamation mark instead, the
   permission from step 4 isn’t there yet.


USING IT
--------
• Just type. Typed a word in the wrong layout — Klavko fixes it and
  switches the layout.
• Settings: click the flag in the menu bar → Settings…
  They are arranged in tabs at the top. The app language (English,
  Українська and others) is on the General tab.

Hotkeys (can be changed in Settings):
• ⇧ ⇧ (Shift twice) — switch the layout of the word.
• ⌥ ⌥ (Option twice) — switch the layout of the selected text or of
  everything you just typed.
• ⌘ ⌘ (Command twice) — translate the selected text.
• ⌃Q — text from the screen: select an area, Klavko reads and translates it.
• ⌥⌘V — clipboard history: find something copied earlier, ↩ — paste.
• fn (🌐) — voice input: press, speak, press again — the text appears at
  the cursor. Return inserts too. Esc — cancel.

Voice input:
• On the first recording macOS asks for access to the microphone and to
  speech recognition — allow it.
• The microphone, turning music down while dictating and the history of
  what you dictated (with search) are on the Voice tab in Settings.
• So that the fn (🌐) key does nothing else:
  System Settings → Keyboard → “Press 🌐 key to” → “Do Nothing”.
• For much better quality (punctuation, automatic language detection):
  Settings → Voice tab → “Download (~600 MB)”.
  This is the NVIDIA Parakeet model; it is downloaded once and then works
  offline. Without it the built-in macOS recognition is used.
• If you fix a word by hand after dictating, Klavko offers for 5 seconds to
  remember how to write it (Return — yes, Esc — no).
  The vocabulary is on the Voice tab, where it can be changed.

Translation:
• Select text anywhere and press ⌘ twice. Text in your language is
  translated into the chosen one, any other text into yours. The language
  pair (Ukrainian ↔ English at first) is set on the Text tab, and the
  languages at the top of the translation panel can be changed right there.
  Return — replace the selection, ⌘C — copy, Esc — close.
• The macOS translator does the work on your Mac (needs macOS 15 or later).
  The first time, macOS offers to download the languages — agree.

Text from the screen:
• Press ⌃Q and select an area of the screen with the mouse (Esc — cancel).
  Klavko reads the text in it and translates it. The Translation /
  Original switch shows the recognized text without translation; Copy takes
  it.
• A QR code: select it the same way — Klavko shows what it holds; if it is
  a link, Return opens it in the browser.
• The first time, macOS asks for the Screen Recording permission:
  System Settings → Privacy & Security → Screen & System Audio Recording →
  turn on Klavko, then restart it.

Clipboard history:
• Press ⌥⌘V: everything you copied appears (text, links, pictures, files).
  Type to search; ↑↓ — choose; Return — paste; ⌘P — pin; ⌘⌫ — delete;
  Esc — close.
• The history stays on your Mac only (30 days by default). Passwords from
  password managers are never recorded. Settings — Clipboard tab.

IF SOMETHING DOESN’T WORK
-------------------------
• Nothing gets fixed: check the permission from step 4 and that you have
  at least two layouts (for example English and Ukrainian).
• Klavko gets in the way in some app: click the flag → Don’t Fix in
  “app name”.
• A lock icon instead of the flag: another app has secure input on right
  now (for example a password field) — this is temporary.


UNINSTALLING
------------
Click the flag → Quit Klavko, then drag Klavko.app from Applications to the
Trash. The voice model (if you downloaded it) is in
~/Library/Application Support/FluidAudio/Models/parakeet-ultra, and the
clipboard history in ~/Library/Application Support/Klavko. You can delete
them too.
